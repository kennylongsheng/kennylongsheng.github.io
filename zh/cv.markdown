## 工作經歷 {#experience}

### IC 驗證工程師 · Phison Electronics Corp.

*2021 年 3 月加入 · 臺灣苗栗*

工作內容涵蓋 FPGA 與 ASIC 設計的驗證測試規劃、測試案例開發、結果分析與整合測試。

**驗證規劃與開發**

- 制定並執行 FPGA 與 ASIC 專案的 IC 驗證測試計畫。
- 開發及執行測試案例，分析失敗原因，並與 IC 設計工程師討論設計行為。
- 調整測試向量與邊界條件情境，擴展功能測試涵蓋範圍。

**跨 IP 整合與協作**

- 參與跨 IP 功能測試，調查系統元件之間的異常互動。
- 依其他 IP 團隊的驗證需求，提供客製化功能 API。
- 與韌體、硬體及 SoC 團隊協作除錯，並在驗證環境限制下尋找替代測試方法。

**記憶體規範與問題分析**

- 研讀 SDRAM JEDEC 規範，將 DDR4 與 LPDDR4 等規範內容運用於驗證需求與測試規劃。
- 支援客戶問題調查與 RMA 案件，進行故障排查、失效分析與根因釐清，並向上游團隊回報調查結果。
